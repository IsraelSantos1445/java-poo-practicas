# Unidad 4: Clases y objetos

| Paquete | Qué muestra |
|---|---|
| `practicas` | Clases con atributos privados, constructores y getters/setters: `Persona`, `Alumno`, `Profesor`, `Materia`, `Empleado`, `Vehiculo`, `Celular` y `Computadora`. Cada una tiene su clase `Prueba...` con el `main`. |
| `excepciones` | Manejo de excepciones con `try/catch`, `throws` y `throw`. |

## Cómo ejecutarlo

Desde esta carpeta:

```
javac -d out $(find src -name '*.java')
java -cp out practicas.PruebaPersona
```
