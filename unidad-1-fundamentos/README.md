# Unidad 1: Fundamentos

Programas con ciclos, condicionales y entrada de datos mediante ventanas (`JOptionPane`).

| Clase | Qué hace |
|---|---|
| `MenuConWhile` | Menú de opciones con un `while` infinito y un `switch`. |
| `VentaDeNaranjas` | Para 15 clientes calcula el total, aplica descuento si compran más de 10 kilos y acumula lo que percibe la tienda. |
| `VerificacionDeAutos` | Promedio, máximo y mínimo de los puntos contaminantes de 25 automóviles. |
| `DescuentosTeatro` | Descuento por categoría de edad y acumulado de cada categoría. |

## Cómo ejecutarlo

Desde esta carpeta:

```
javac -d out $(find src -name '*.java')
java -cp out fundamentos.MenuConWhile
```
